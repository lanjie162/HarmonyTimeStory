# [QA] V2.6 真机退出问题分析 — 测试用例正确性审查

## 结论先行

**根因已定位**：`V2RegressionTestKit.ets` 中的 `coldStartMainApp()` 使用 `ON.text('时光故事')` 作为主壳页识别锚点，但当前 `ShellPage.ets` 源码中**不存在此文本**（该文本仅在未注册的 `Index.ets` 中）。导致冷启动函数走 `ensureOnMainShell()` 降级路径，执行 4 次 `pressBack()`，**将应用从壳页逐出**，表现为"进入页面后立即退出"。

**影响范围**：所有依赖 `coldStartMainApp()` 的 E2E 测试（共 14 个文件，约 60 条用例）都会因同一根因失败。

**关键发现**：共发现 4 类问题，其中 1 个阻塞级（根因）、2 个严重级、1 个中等级。

## 二、问题详细分析

### 问题 #1（阻塞级）：`coldStartMainApp()` 主壳锚点失效

**文件**：`entry/src/ohosTest/ets/test/V2RegressionTestKit.ets`

**代码位置**：第 87-108 行

```typescript
export async function coldStartMainApp(): Promise<Driver> {
  const delegator = abilityDelegatorRegistry.getAbilityDelegator();
  await delegator.startAbility(want);
  const driver = Driver.create();
  let shell = await driver.findComponent(ON.text('时光故事'));  // ← 锚点文本不存在
  if (shell === null) {
    await ensureOnMainShell(driver);  // ← 走降级路径
    // ...
  }
}
```

**降级路径 `ensureOnMainShell()`**（第 121-149 行）：
- 每轮查找"时光故事"→ null
- 查找"返回列表"→ null
- 查找"返回"→ null
- 执行 `pressBack()` ← **在壳页按返回会退出应用**
- 循环 4 次后抛异常

**影响**：14 个 E2E 测试文件的所有用例均无法正常运行。

**修复方向**：
- 将主壳锚点从 `ON.text('时光故事')` 改为 `ON.text('人物')` 或 `ON.text('故事')`（当前 ShellPage 实际存在的 Tab 文本）
- 或为 ShellPage 补回标题文本

---

### 问题 #2（严重）：ShellPage 调试按钮已移除，测试仍引用

**文件**：`entry/src/ohosTest/ets/test/V2RegressionShell.test.ets`

**用例 `V2_D0_shell_debug_state`**（第 45-63 行）引用了不存在的 UI 元素：
- `'调试：切换占位状态'` — 源码中不存在
- `'从上方任选入口开始'` — 源码中不存在
- `'正在准备…'` — 源码中不存在
- `'导航未就绪，可稍后重试'` — 源码中不存在

**用例 `V2_D0_shell_main_entries`**（第 24-43 行）：
- 第 40 行：`await clickButtonByText(driver, '返回');` — PersonPage 和 ShellPage 中均无"返回"按钮

**修复方向**：
- 移除 `V2_D0_shell_debug_state` 测试用例（功能已移除）
- 修复 `V2_D0_shell_main_entries`：移除"返回"点击逻辑，改为通过 Tab 切换验证

### 问题 #3（严重）：隐私页测试定位错误

**文件**：`entry/src/ohosTest/ets/test/V2RegressionPrivacy.test.ets`

**问题**：
- 第 29 行：`const settingsBtn = await driver.findComponent(ON.text('设置'));` — ShellPage 中无"设置"文本
- 实际入口是 `⋮` → `隐私说明`，不是 `设置 → 隐私`
- 测试静默跳过（`settingsBtn` 为 null），实际未执行任何验证

**修复方向**：
- 将导航路径改为：点击 `⋮` → 点击 `隐私说明`
- 或直接使用 `router.pushUrl({ url: 'pages/privacy/PrivacyPage' })` 导航

---

### 问题 #4（中等）：`OhosTestRdbContext` 重复调用 `startAbility()`

**文件**：`entry/src/ohosTest/ets/test/OhosTestRdbContext.ets`

**代码位置**：第 80-83 行

```typescript
} else {
    await delegator.startAbility(want);  // ← 缓存命中后仍调用 startAbility
    await sleepMs(300);
}
```

当 `cachedRdbContext` 已缓存时，仍调用 `startAbility()`，可能在测试执行过程中意外重启 Ability。

**受影响的 L3 测试**：`MigrationTier2`、`L3PersonService`、`L3StoryService`、`L3LinkPhotoService`（均通过 `TestDbHelper` → `resolveRdbCapableContext()`）

**修复方向**：
- 缓存命中时跳过 `startAbility()` 调用，直接返回已缓存的 context

## 三、修复方案

### 修复优先级

| 优先级 | 问题 | 修复文件 | 工作量 |
|--------|------|----------|--------|
| **P0** | 问题 #1: 主壳锚点失效 | `V2RegressionTestKit.ets` | 小 |

| **P1** | 问题 #3: 隐私页测试定位 | `V2RegressionPrivacy.test.ets` | 小 |
| **P2** | 问题 #4: 重复 startAbility | `OhosTestRdbContext.ets` | 小 |

### 具体修复步骤

#### Step 1: 修复 `V2RegressionTestKit.ets` — 主壳锚点

```diff
- function mainShellMatcher(): On {
-   return ON.text('时光故事');
- }
+ function mainShellMatcher(): On {
+   return ON.text('人物');
+ }
```

同时修改 `coldStartMainApp()` 中的快速检查：
```diff
- let shell = await driver.findComponent(ON.text('时光故事'));
+ let shell = await driver.findComponent(ON.text('人物'));
```

#### Step 2: 修复 `V2RegressionShell.test.ets`

- 删除 `V2_D0_shell_debug_state` 用例（第 45-63 行）
- 修改 `V2_D0_shell_main_entries`：
  - 移除 `await clickButtonByText(driver, '返回');` 及相关断言
  - 将壳页标题断言改为当前 ShellPage 实际存在的元素
  - 替换为：
    ```typescript
    await assertTextExist(driver, '人物');
    await assertTextExist(driver, '故事');
    // 点击人物 Tab → 验证进入
    // 不再需要点击"返回"（Tab 切换即可回到壳页）
    ```

#### Step 3: 修复 `V2RegressionPrivacy.test.ets`

将导航路径从 `设置 → 隐私` 改为 `⋮ → 隐私说明`：
```typescript
// 点击 ⋮ 打开更多菜单
const moreBtn = await driver.findComponent(ON.text('⋮'));
if (moreBtn !== null) {
  await moreBtn.click();
  await driver.waitForIdle(300, 800);
  // 点击隐私说明
  const privacyBtn = await driver.findComponent(ON.text('隐私说明'));
  if (privacyBtn !== null) {
    await privacyBtn.click();
    await driver.waitForIdle(300, 800);
  }
}
```

#### Step 4: 修复 `OhosTestRdbContext.ets`

省略缓存命中时的 `startAbility()` 调用：
```diff
  } else {
-   await delegator.startAbility(want);
-   await sleepMs(300);
+   // 缓存命中，无需重启 Ability
  }
```

## 五、假设与决策

- **假设 1**：当前 ShellPage 的极简版是 V2.6 封板版的预期 UI，不会恢复旧版标题和调试按钮
- **假设 2**：`Index.ets` 是遗留文件，不参与当前版本的路由
- **决策 1**：直接删除 `V2_D0_shell_debug_state` 测试用例，因为对应的调试功能已从 ShellPage 中移除
- **决策 2**：将主壳锚点从 `时光故事` 改为 `人物`，因为 `人物` 是 ShellPage 当前版本中始终存在的 Tab 文本
