# V2.4 人脸任务废弃通晒

## 废弃原因

V2.4 人脸方案重大变更：

- **faceDetector API 不输出特征向量**：仅有 rect/points/pose/probability，无 embedding/float[]
- **原 DoD「输出人脸特征向量（float[]）可供聚类消费」不可达**
- **聚类方案从 K-means/pairwise 改为贪心+两级参考脸 + faceComparator 1v1 比对**

人脸功能整体延后至 V5，基于新 PRD `[产品]人脸识别与人物关联功能PRD-v1-draft.md` 重新派发。

## 废弃任务

| T-n | 任务摘要 | 废弃理由 |
|-----|----------|----------|
| T-35 | VisionImpl · 单图检测封装 | faceDetector 不输出特征向量，原 DoD 不可达 |
| T-36 | VisionImpl · 聚类引擎+双模式 | 聚类方案变更，K-means/pairwise 改为贪心+两级参考脸 |
| T-37 | 导入条件真实逻辑（人脸部分） | 人脸条件延后至 V5；保留时间/地点/AND 为 T-37a |
| T-38 | 人脸开关 IM-10 | 人脸功能整体延后 |
| T-39 | 形态三真实聚类 IM-03 | 依赖人脸聚类，延后 |
| T-40 | 低端机降级 IX-02 | 降级对象是人脸，延后 |
